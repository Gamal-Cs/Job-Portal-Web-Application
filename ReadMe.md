# Job Portal

A full-stack job portal web application built with **Java, Spring Boot, Spring MVC, Spring Data JPA, Thymeleaf, and MySQL**.

The application is designed to connect **job seekers** and **recruiters** through a single platform. Users can register according to their user type and maintain profiles based on their role.

## Current Features

- User registration
- User type management
- Duplicate email validation
- Job seeker profiles
- Recruiter profiles
- Job seeker skills management
- Thymeleaf-based web interface
- Layered architecture using Controllers, Services, Repositories, and Entities

> 🚧 **Project Status:** This application is currently under development. Additional features such as job posting, job searching, applications, authentication, and dashboards are planned.
